# Инструкция по установке и запуску

## Почему нет готового .exe-файла

Программа состоит из двух частей: десктопное приложение (Electron) и расчётный модуль на Python с нейронными сетями. Чтобы собрать всё в один установочный .exe, который заработает на чужом компьютере «из коробки», в инсталлятор пришлось бы упаковать:

- сам Python со всеми библиотеками (torch, transformers, diffusers — это около 2–3 ГБ);
- веса предобученной модели SDXL (6,5 ГБ);
- интерфейс на Electron.

В сумме получилось бы приложение на 9–10 ГБ, которое не прикрепится в эос, так как это сильно выходит за ограничения по размеру. Поэтому я оставил «обычный» способ установки через стандартные команды Python и Node.js — он дольше, но рабочий.

## Что нужно на компьютере

- **Python 3.10 или новее** — [https://www.python.org/downloads/](https://www.python.org/downloads/)
- **Node.js 18 или новее** и **npm** — [https://nodejs.org/](https://nodejs.org/) (нужен только для десктопного приложения, для запуска из командной строки не обязателен)
- около **10 ГБ свободного места** — модель SDXL скачается из интернета при первом запуске
- видеокарта NVIDIA или процессор Apple Silicon — для разумной скорости. На обычном процессоре одна картинка будет считаться 10–30 минут, на видеокарте NVIDIA или процессоре Apple Silicon - процесс идет кратно быстрее

## Установка

1. Открыть командную строку (на Windows — PowerShell или cmd) в папке проекта.

2. Установить зависимости Python:
   ```
   pip install -r requirements.txt
   ```
   Эта команда подтянет torch, transformers, diffusers и всё остальное. Может занять 5–10 минут — там около 2 ГБ библиотек.

3. (Только если нужно десктопное приложение.) Установить зависимости Node.js:
   ```
   cd app
   npm install
   ```

## Запуск

### Вариант 1. Десктопное приложение

```
cd app
npm run dev
```

Откроется окно чата. В поле ввода пишем описание желаемой картинки, нажимаем «Сгенерировать», ждём результата. По мере генерации показываются промежуточные превью.

При самом первом запуске программа скачает веса модели SDXL — это разовая операция, потом всё будет быстрее. Скачивание идёт автоматически, нужен интернет.

### Вариант 2. Командная строка (без интерфейса)

```
python generate.py "a majestic lion in the savannah"
```

Готовая картинка сохранится в папку `output/`.

С дополнительными параметрами:
```
python generate.py "futuristic cityscape at night" --steps 30 --guidance 7.5 --seed 42
```

## Важно: промпты только на английском

Текстовые описания нужно писать **на английском языке**. Это особенность модели SDXL — её обучали на англоязычных описаниях, и русский она не понимает (точнее, понимает очень плохо — будет генерировать что-то невнятное).

Примеры рабочих промптов:

- `a majestic lion in the savannah, golden hour lighting`
- `mountain landscape at sunrise, mist in the valley`
- `cozy cabin in the woods, autumn forest, warm light`
- `futuristic cityscape at night, neon lights, rain`

Чем подробнее описание, тем лучше результат. Можно добавлять стиль: `oil painting`, `photorealistic`, `cinematic lighting` и т.п.

## Если что-то пошло не так

- **Ошибка «No module named torch»** — не установлены Python-зависимости. Запустите `pip install -r requirements.txt`.
- **Ошибка про CUDA или видеокарту** — программа не нашла видеокарту и попытается работать на процессоре. Это нормально, просто будет медленно.
- **Скачивание модели зависло** — нужен стабильный интернет, файл большой (~6,5 ГБ). Проще всего перезапустить, скачивание продолжится с того же места.
- **На Windows в консоли русские буквы превратились в кракозябры** — это особенность стандартной кодировки Windows. На работу программы не влияет, картинки всё равно сгенерируются.
