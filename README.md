# Генерация изображений диффузионной моделью

Курсовая работа по теме «Генерация изображений пейзажей на основе диффузионных моделей нейросетей».

Программа берёт текстовое описание и рисует по нему картинку. Внутри используются готовые предобученные нейросети из SDXL — это текстовые кодировщики, автокодировщик и сеть, которая умеет предсказывать шум. Сами эти сети я не обучал, но всё, что вокруг них (как именно из шума получается картинка), написано с нуля: стохастическое уравнение, расписание шума, метод Эйлера, направление без классификатора.

## Что нужно для запуска

- Python 3.10 или новее
- Node.js 18+ и npm — только если нужно десктопное приложение
- около 6,5 ГБ свободного места на диске (модель SDXL скачается при первом запуске)
- macOS с Apple Silicon (видеокарта MPS), либо NVIDIA-видеокарта (CUDA), либо обычный процессор

## Установка

```bash
# 1. Зависимости Python
pip install -r requirements.txt

# 2. Десктопное приложение (по желанию)
cd app
npm install
```

## Запуск

### Через десктопное приложение (Electron)

```bash
cd app
npm run dev
```

Откроется окно чата. Пользователь вводит описание желаемой картинки, нажимает «Сгенерировать», программа показывает прогресс и промежуточные превью.

### Через командную строку

```bash
python3 generate.py "a majestic lion in the savannah, golden hour lighting"

# С дополнительными параметрами
python3 generate.py "futuristic cityscape at night" --steps 20 --guidance 9.0 --seed 42
```

### Параметры командной строки

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `prompt` | — | Текстовое описание желаемой картинки (обязательный) |
| `--steps` | 30 | Количество шагов численного метода |
| `--guidance` | 7,5 | Сила влияния запроса на результат |
| `--seed` | случайное | Зерно случайности (для воспроизводимости) |
| `--width` / `--height` | 1024 | Размер картинки в пикселях |
| `--negative_prompt` | стандартный набор «качество» | Что НЕ должно появиться на картинке |
| `--output` | ./output | Папка для сохранения результата |
| `--save_intermediates` | выключено | Сохранять ли промежуточные шаги |

## Что я писал сам

Готовыми я взял только сами нейросети — CLIP-L, OpenCLIP-G, автокодировщик VAE и U-Net. Они подгружаются с HuggingFace и используются как чёрные ящики. А сам диффузионный процесс собран с нуля:

- **Стохастическое уравнение (VP-SDE)** — прямое уравнение зашумления и обратное к нему. Здесь же лежат маленькие функции вроде перевода предсказанного шума в функцию оценки.
- **Метод Эйлера** — простой численный метод первого порядка, которым и решается обратное уравнение. Это и есть то, на чём держится вся генерация.
- **Расписание шума** — функция, которая говорит, сколько шума добавлять на каждом шаге. Использую то же расписание, на котором обучали SDXL, иначе нейросеть «не узнает» свои значения.
- **Направление без классификатора** — приём, благодаря которому картинка реально слушается текстового запроса. Сеть вызывается дважды (с описанием и без), а её ответы смешиваются с заданной силой.
- **Сборка всего вместе** — модуль, который подгружает нейросети, кодирует текст, крутит цикл шагов метода Эйлера и в конце получает готовую картинку.

## Структура проекта

```
├── generate.py              # запуск из командной строки
├── bridge.py                # мост между Electron-приложением и пайплайном
├── app/                     # десктопное приложение (Electron + React + TypeScript)
│   ├── electron/            # главный процесс Electron, preload-скрипт
│   └── src/                 # React-компоненты, стили, типы
├── src/
│   ├── pipeline/            # основной процесс генерации (склейка всех частей)
│   ├── sde/                 # стохастическое уравнение VP-SDE
│   ├── solvers/             # численный метод Эйлера
│   ├── schedulers/          # расписание шума
│   ├── guidance/            # направление без классификатора
│   ├── models/              # загрузка предобученных компонентов SDXL
│   └── utils/               # выбор устройства, работа с картинками, зерно случайности
└── requirements.txt
```

## На каком оборудовании работает

В первую очередь программа делалась под macOS с процессором Apple Silicon. Если в системе есть видеокарта NVIDIA — тоже работает (через CUDA). На обычном процессоре генерация будет очень медленной, поэтому без видеокарты пользоваться этим не очень удобно.
